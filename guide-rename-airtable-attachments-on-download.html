Rename Airtable attachments when downloading (use field values as file names)

Name downloaded Airtable files after field values such as invoice number or customer, without renaming them inside Airtable.

Two different jobs: renaming inside Airtable vs renaming on download

People searching for this mean one of two things. Renaming inside Airtable changes the file's stored name for everyone who opens the base — you do it by hand per file, or with a script or automation, and it edits your live data. Renaming on download only names the copies you save to disk; the files in Airtable keep their original names and nothing in the base changes. This guide is about renaming on download. If you actually need the stored names changed, start with the free in-Airtable method below and expect it to be slow past a few dozen files.

Why rename

Uploaded files are often IMG_4821.jpg or scan (3).pdf. A name like INV-1042_Acme.pdf is searchable once it leaves Airtable.

Free method: rename inside Airtable

You can rename an attachment from the expanded record (hover the file, click the rename icon) as described in Airtable's help. Fine for a few files; slow for hundreds.

Free method: rename in your download script

Build the target name from fields, e.g. f"{fields['Invoice']}_{n}{ext}", keep the original extension, and add a counter when a record has several files. Doing it in the script leaves Airtable untouched.

Three naming rules that work

Whatever tool you use, templates built on these rules stay findable months later:

  1. Lead with the key a human searches by — invoice number, client name or date first, not the camera's file name.
  2. Plan for several files per record — add a counter (or keep part of the original name) so file two does not collide with file one.
  3. Keep names sortable and filesystem-safe — ISO dates (2026-10-28), no slashes or colons, and always keep the original extension.

When two files want the same name

Duplicates happen whenever a template ignores the one thing that differs between files. You have three escapes: a counter suffix (BaseDrop appends one automatically instead of overwriting), falling back to the original file name as part of the template ({filename}), or adding the record ID ({recordId}) when names must stay unique across a whole base. Whichever you pick, keep a mapping: BaseDrop's index.csv records each new name alongside its record and original filename, so a renamed file can always be traced back.

FAQ

Does renaming change files in Airtable?

No. Only the downloaded copies are renamed.

Can I rename attachments inside Airtable instead?

Yes — by hand in the expanded record, or with a script or automation. That changes the stored name for everyone and edits your live data. Renaming on download, which this guide covers, leaves Airtable untouched.

What happens if two files get the same new name?

BaseDrop appends a counter suffix instead of overwriting, and index.csv records both the new and the original name. In your own script, add a counter or the record ID to the template.
