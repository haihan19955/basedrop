Frequently asked questions

Getting your files out

Does Airtable let you download all attachments at once?

Not natively. Airtable has no built-in button to download every attachment in a table, so you normally open each file one by one. BaseDrop adds that missing bulk download.

How do I download all attachments from an Airtable table?

Install BaseDrop, paste a read-only personal access token, pick the base, table (and optionally a view) and the attachment fields, then click Download ZIP. Every file is saved into organized ZIP files with an index.csv.

Do attachment download links expire?

Yes. The links in a CSV export or an API response live only a few hours, which is why saving a spreadsheet of links is not a download strategy. BaseDrop fetches fresh links and downloads the files in the same run, so expiry never gets a chance to bite. Background: why Airtable attachment URLs expire.

What about very large tables?

BaseDrop downloads with rate-limit-safe pacing (under Airtable's 5 requests/second), retries failed files, and splits big exports into multiple ZIP parts so your browser does not run out of memory.

Can I export a whole base?

Yes (Pro). Whole-base mode exports every table that has attachment fields, one folder per table.

What happens if a download fails part-way?

BaseDrop paces requests under Airtable's rate limit and retries failed files automatically; very large exports are split into multiple ZIP parts so the browser does not run out of memory. If a run is interrupted, just start it again — in full-backup mode, incremental runs skip files an earlier backup already saved.

Plans, privacy and pricing

Does it work on the Airtable Free plan?

Yes. BaseDrop uses the official Airtable Web API, which is available on the Free plan. Listing records costs 1 API call per 100 records (Free plan: 1,000 calls per workspace per month). Downloading the files themselves does not use API calls, and BaseDrop shows exactly how many calls each run used.

Is my data safe?

Your token is stored only in your browser and only sent to api.airtable.com. Files go straight from Airtable's file servers to your computer – they never pass through a BaseDrop server. The token only needs read scopes.

What does the free version include?

Up to 50 files per run with original file names, from any table or view, plus index.csv. Pro removes the limit and unlocks renaming, folders, whole-base export and full backups.

How does the license work?

Pro is a one-time purchase on Payhip. You receive a license key by email; paste it into BaseDrop. One key works on up to 3 of your own browsers. Refunds automatically deactivate the key.

Pro features

Can I rename files after a field?

Yes (Pro). Use templates such as {field:Client} - {field:Name} - {n}, and optionally put each record in its own folder, including nested folders like {field:Status}/{field:Name}.

Can I choose which attachment fields to download?

Yes. You pick the base, the table (or a view) and exactly which attachment fields to include, so you can leave out fields you do not need — for example internal scans — and keep the export small.

Can BaseDrop back up records as well as files?

Yes (Pro, v1.1). Full backup mode writes, for every table, records.csv and records.json whose attachment cells point to the saved files by relative path, plus schema.json and manifest.json. Incremental mode skips files saved by an earlier backup of the same base; extract all backup ZIPs of a base into one folder. An optional Notion-import CSV is included. Automations, interfaces and formula definitions are not available through the API and are not included.
