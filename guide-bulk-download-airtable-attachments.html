How to bulk download all Airtable attachments (free methods + one-click)

Airtable has no "download all attachments" button. Here are the free ways to do it (CSV + script, Scripting extension, API) and a one-click option.

Why there is no button

Airtable lets you download one attachment at a time from an expanded record. Its own help center says there is no built-in bulk download in the interface and points to the Scripting extension instead (source). A "Download CSV" of a view gives you file names and temporary links, not the files.

The 4 methods at a glance

Every working method uses the same underlying trick — fetch fresh attachment URLs from the API and download the files before the links expire. They differ in how much code you write, what they cost, and what happens past a few hundred files.

Free method 1: CSV export + a download script

  1. Open the view, choose Download CSV.
  2. Within about two hours, run a script that reads each URL from the attachment column and saves the file (wget/curl, PowerShell, or Python).
  3. Prefix each filename with the record ID so two invoice.pdf files do not overwrite each other.
Limits: links expire, attachment cells with several files need splitting, and you have to write or trust a script.

Free method 2: Airtable Scripting extension

Airtable publishes a script (linked from the attachment field article) that generates download commands for a record, view or table. You then run those commands in a terminal before the links expire. Airtable itself notes the script may have limitations, so compare file counts afterwards.

Free method 3: the Web API

Create a personal access token with data.records:read, call List records (100 records per page, follow offset), and download each attachment url right away. Respect the rate limit of 5 requests/second per base; after a 429 wait 30 seconds.

What about a whole base, or several tables?

The free methods above work one view or one table at a time, so a base with eight tables means eight runs — and eight chances to miss one. BaseDrop's free version is also per table or view. BaseDrop Pro adds whole-base export: pick the base once and every table is exported in a single run, each into its own organized ZIP with its own index.csv. If you are doing this as part of leaving Airtable or archiving a project, read the backup guide as well — downloading attachments is only one third of a complete backup.

FAQ

Can Airtable export all attachments at once?

Not from the interface. CSV export only contains temporary links; you need a script, the API or an extension to fetch the files.

Does it work with a filtered view?

Yes. The API accepts a view parameter, so only records visible in that view are exported, using the view's filters.

How many attachments can I download for free?

With BaseDrop's free version, up to 50 files per export — enough for a single view or a small table. The DIY methods (CSV + script, Scripting extension, API) have no file-count limit, but you maintain the script yourself. Pro removes the 50-file limit for a one-time $19.

Can I download attachments from an entire base at once?

Not with Airtable's own tools, and not with the free methods in this guide — they run per view or per table. BaseDrop Pro adds whole-base export, which runs every table in the base in one go. Scheduled, automatic backups are a different job: tools like On2Air Backups do that on a subscription.

Is my data uploaded anywhere when I use an extension?

With BaseDrop, no. It runs locally in your browser using your own Airtable token, and files are written directly from Airtable to your disk. As a rule, before pasting a token into any tool, check where the processing happens — browser-local and server-side tools make very different privacy promises.
