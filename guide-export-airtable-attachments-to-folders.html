Export Airtable attachments into folders (per record, client or project) for Drive or Dropbox

How to export Airtable attachments organised into folders by record or by a field like Client, ready to drop into Google Drive or Dropbox.

The goal

A folder tree like Client/Project/file.pdf rather than one flat pile, so you can drag it into Google Drive or Dropbox and colleagues find files without Airtable.

Free method: script with a folder column

Extend any CSV or API script so the save path is built from fields, e.g. {Client}/{record id}/{filename}. Strip characters that are illegal in file names (/ \ : * ? " < > |) and handle empty values.

Free method: automation straight to cloud storage

Make or Zapier can watch records and upload each attachment to a Drive/Dropbox folder named after a field. This is good for ongoing sync, but each file counts as operations on those platforms' plans.

With BaseDrop (Pro)

Set a folder template such as {field:Client}/{field:Project}; a "/" creates nested folders. Unzip the export into your synced Drive or Dropbox folder and the desktop client uploads it. BaseDrop does not connect to Drive or Dropbox accounts itself, so nothing else gets access to your cloud storage.

FAQ

Can I sync continuously?

BaseDrop exports on demand. For continuous sync use an automation tool.
